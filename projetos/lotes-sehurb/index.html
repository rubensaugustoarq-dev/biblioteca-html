Primeiro uso

Prepare uma vez. Depois, é só abrir.

  1. Instale Python 3.12 de 64 bits e Node.js 22 ou superior, disponíveis pelo terminal.
  2. Extraia o ZIP e abra projetos/lotes-sehurb/software.
  3. Execute Preparar Lotes SEHURB.cmd. A preparação precisa de internet para instalar as dependências.
  4. Execute Iniciar Lotes SEHURB.cmd. A Home abre em 127.0.0.1:8765.

Esta página apresenta e distribui o software. O motor Python funciona no seu computador; o GitHub Pages não executa o aplicativo. Os projetos pessoais não estão incluídos no repositório.
