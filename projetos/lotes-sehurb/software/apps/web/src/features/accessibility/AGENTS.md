# Acessibilidade

- Ler docs/ACESSIBILIDADE.md antes de alterar este módulo.
- Manter interface e motor independentes de ENL e de operações de edição da Infra.
- Rampas são sobreposições vinculadas a uma via/lado; jamais descontar ou adicionar suas áreas nos quantitativos das calçadas/pavimentos.
- Não aceitar rampas sem calçada, não recortar a geometria para caber e não anunciar certificação normativa completa.
- Preservar IDs, CRS, histórico, revisão, salvar/reabrir e Salvar como. Vínculos inválidos devem permanecer identificáveis e editáveis.
