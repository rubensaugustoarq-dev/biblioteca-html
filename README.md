# Biblioteca HTML

Biblioteca de ferramentas e projetos interativos em HTML.

Os projetos serão disponibilizados por links através do GitHub Pages.

## Publicação

Configurar GitHub Pages para publicar a branch `fitquick`, na pasta raiz (`/`).

Os arquivos HTML devem incluir seus recursos ou usar caminhos relativos aos arquivos deste repositório.
